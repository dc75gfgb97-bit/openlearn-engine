# OpenLearn Engine 中文简要使用说明

[打开在线演示](https://dc75gfgb97-bit.github.io/openlearn-engine/)

1. 页面打开后自动加载原创“社区图书馆预算决策”故事。
2. 点击选项探索不同分支；测验选答后先看解释，再点击 Continue。
3. 完成后查看首次作答结果和逐题解释；Start a fresh session 开始新一轮。
4. 同一浏览器会保存当前场景和已提交答案。刷新可续读；清理浏览器数据会删除记录。
5. Download sample story 下载 JSON 样例。修改后用 Load your story 导入；无效格式会显示错误，保留当前故事。

本地开发：安装 Node.js 22.12+、pnpm 11，运行 `pnpm install --frozen-lockfile`，再运行 `pnpm dev`。`pnpm test` 运行测试，`pnpm build` 检查类型并生成 `docs/` 静态站点。
