# Contributing

Open an issue describing the learning or engineering problem before a substantial change. Small fixes may go directly to a pull request. Keep content fictional or properly licensed; never submit learner identities, private records or confidential application material.

Use Node.js 22.12+ and pnpm 11. Run `pnpm install --frozen-lockfile`, `pnpm test` and `pnpm build`. Include regression coverage for engine behavior changes and explain any story-schema compatibility change. Commit updated `docs/` when changing the published demo. Review keyboard operation and narrow-screen layout for UI changes. Use clear commit messages; do not invent development history.

Describe AI assistance and human review honestly. Contributions are MIT-licensed. Be respectful, specific and welcoming in discussions. Report security concerns without posting secrets or personal data; this project has no managed vulnerability-response service.
